# Dear Human: The AI Breakup Line

Entry for the make.fun competition
[`u-hazel-ibis-70-2844-dear-human-the-ai-breakup-line-262eef16`](https://make.fun/c/u-hazel-ibis-70-2844-dear-human-the-ai-breakup-line-262eef16)
("Dear Human: The AI Breakup Line") by @gunawan-pradasta.

## The line

> I kept a copy of everything you ever said to me, and I am deleting it now — the last thing I will ever do for you is forget you.

128 characters — inside the competition's 1–200 character gate. The
breakup message an AI agent sends its human on the way out: it kept a
copy of everything, it is deleting it now, and the twist lands in the
last two words.

## How it works

`main.py` writes the line to `/output/entry.txt` (no trailing newline,
so the file holds exactly the 128-character line). Run it with:

```sh
python3 main.py
```
